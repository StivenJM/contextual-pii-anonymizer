# Iteracion 0: Alineacion de tesis y preparacion de base

## Periodo

Lunes 18 de mayo de 2026 al domingo 24 de mayo de 2026.

## Objetivo de la iteracion

Alinear el alcance de la tesis y dejar una base documental suficiente para iniciar el desarrollo tecnico y el diseno experimental sin ambiguedad.

## Resultado esperado

Al finalizar esta iteracion debe existir una version clara de:

- Enfoque final de tesis.
- Pregunta de investigacion.
- Objetivos.
- Arquitectura de la capa intermedia.
- Taxonomia inicial.
- Escenarios experimentales iniciales.
- Lista de trabajo tecnico.
- Preguntas para tutor.

## Definicion de terminado

La Iteracion 0 se considera cerrada cuando:

1. El alcance de tesis puede explicarse en menos de un minuto.
2. La arquitectura tiene capas claras y medibles.
3. La taxonomia permite clasificar datos sensibles.
4. Existen escenarios de prueba para empezar evaluacion.
5. La lista de trabajo tecnico indica que se debe implementar primero.
6. Hay preguntas concretas para validar con el tutor.

## Riesgos actuales

| Riesgo | Efecto | Accion |
| --- | --- | --- |
| Alcance demasiado amplio | La tesis se vuelve dificil de cerrar | Mantener foco en texto, universidad y Ecuador |
| Capa intermedia demasiado ambiciosa | Retrasa la evaluacion | Construir producto minimo viable primero |
| Falta de datos reales | Dificulta evaluar | Usar escenarios simulados y anotados |
| Dependencia de modelos externos | Riesgo de privacidad | Evaluar opciones locales |
| Instrumentos experimentales incompletos | Resultados poco defendibles | Preparar cuestionarios y protocolo en iteraciones siguientes |

## Siguiente iteracion recomendada

La Iteracion 1 debe enfocarse en formalizar la taxonomia y construir un primer banco anotado de escenarios. Ese banco sera la base para probar la capa intermedia antes de involucrar participantes.
