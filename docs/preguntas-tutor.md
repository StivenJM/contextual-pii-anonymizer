# Preguntas para validar con tutor o director

## Proposito

Estas preguntas ayudan a cerrar el alcance de la tesis antes de avanzar demasiado en implementacion.

## Preguntas sobre enfoque

1. Es adecuado enfocar la tesis en la comparacion entre desidentificacion manual y capa intermedia, diferenciando usuarios tecnicos y no tecnicos?
2. El contexto universitario ecuatoriano es suficientemente especifico como aporte aplicado?
3. Conviene mantener el estudio limitado a texto en espanol?
4. La contribucion principal debe formularse como tecnica, experimental o socio-tecnica?

## Preguntas sobre alcance

1. La capa intermedia debe integrarse realmente con un modelo de lenguaje grande o basta con simular el flujo previo al envio?
2. Es necesario que la capa intermedia funcione completamente local o se permite usar modelos externos durante el prototipo?
3. Que tipos de datos sensibles deben ser obligatorios en la evaluacion?
4. Se debe incluir RUC y cedula desde la primera version?
5. Es aceptable trabajar con datos ficticios pero realistas para proteger a los participantes?

## Preguntas metodologicas

1. El diseno experimental con usuarios tecnicos y no tecnicos es adecuado para el objetivo?
2. Cuantos participantes son razonables para una prueba piloto y para la muestra principal?
3. La comparacion debe ser entre grupos independientes o con los mismos usuarios usando ambas condiciones?
4. Que prueba estadistica seria recomendable segun el tamano de muestra?
5. El indice de exposicion propuesto es aceptable como metrica principal?

## Preguntas sobre instrumentos

1. El cuestionario inicial debe medir conocimiento de informacion de identificacion personal, riesgos de modelos de lenguaje grandes y buenas practicas?
2. Conviene usar una escala tipo Likert para usabilidad y percepcion de riesgo?
3. Los escenarios experimentales deben ser completamente simulados?
4. Cuantos escenarios deberia resolver cada participante para evitar fatiga?

## Preguntas tecnicas

1. Es suficiente una capa intermedia hibrido con expresiones regulares, reconocimiento de entidades nombradas y reglas contextuales para el alcance de tesis?
2. Se espera fine-tuning de un modelo o basta con adaptar reglas y evaluar el rendimiento?
3. La preservacion semantica mediante etiquetas como `<PERSONA_1>` y `<CEDULA_1>` es una estrategia adecuada?
4. Que metricas tecnicas deben reportarse: precision, exhaustividad, F1, tiempo de procesamiento, reduccion de exposicion?
5. Se debe comparar contra una herramienta base como Presidio o solo contra desidentificacion manual?

## Preguntas normativas

1. Que profundidad debe tener el analisis de la normativa ecuatoriana de proteccion de datos?
2. Debe incluirse una matriz de cumplimiento legal o solo recomendaciones institucionales?
3. Hay restricciones eticas especificas para recolectar consultas de participantes?
4. El consentimiento informado debe ser validado por alguna instancia institucional?

## Preguntas de cierre

1. Cuales son los tres entregables minimos que deben estar listos para considerar viable la tesis?
2. Que parte del proyecto deberia priorizarse si el tiempo se reduce?
3. Que riesgos ve en el alcance actual?
4. Que deberia quedar explicitamente fuera de alcance?
