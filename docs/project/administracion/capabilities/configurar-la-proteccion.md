# Configurar la protección

## ¿Qué permite hacer?

Permite cambiar los recursos y criterios utilizados para detectar y proteger información sin alterar la definición central de qué categorías reconoce el producto.

## ¿Quién puede utilizarla?

El administrador modifica la configuración. El investigador puede consultar las versiones utilizadas para interpretar y reproducir los resultados.

## ¿Cómo funciona?

1. El administrador consulta las opciones y la configuración vigente.
2. Selecciona un modelo disponible y completa su relación con las categorías del sistema.
3. Ajusta reconocedores, diccionarios, umbrales y prioridades cuando corresponde.
4. Define el tratamiento predeterminado para cada categoría.
5. El sistema valida que la propuesta sea completa y coherente.
6. La configuración aceptada se utiliza en las interacciones posteriores.

## Reglas importantes

- Un modelo solo puede seleccionarse si está disponible para el sistema.
- Toda categoría producida por el modelo debe tener un tratamiento explícito o una relación válida con la clasificación común.
- Un reconocedor o diccionario habilitado siempre se asocia con una categoría existente.
- Una propuesta inválida no reemplaza la última configuración válida.
- Los cambios relevantes conservan la información necesaria para identificar qué configuración se utilizó en cada resultado experimental.

## Resultado

El sistema aplica una configuración validada y trazable sin requerir que las personas participantes conozcan sus detalles.
