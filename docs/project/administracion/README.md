# Administración

## ¿Para qué sirve?

Este módulo permite ajustar cómo el sistema detecta y trata información sensible sin modificar la clasificación central del producto.

## ¿Quiénes participan?

- **Administrador**: mantiene modelos, reconocedores, diccionarios y reglas.
- **Investigador**: consulta la configuración relevante para interpretar los resultados del estudio.

## Capacidades principales

- Consultar los modelos de detección disponibles y seleccionar uno.
- Relacionar las categorías de cada modelo con la clasificación del sistema.
- Crear, modificar, habilitar o deshabilitar reconocedores estructurales.
- Administrar diccionarios y sus entradas.
- Ajustar umbrales y prioridad entre formas de detección.
- Definir el tratamiento aplicable a cada categoría.
- Consultar qué configuración se encuentra vigente.

## Conceptos importantes

- **Modelo disponible**: opción de detección preparada para ser utilizada por el sistema.
- **Mapeo**: relación entre las categorías de un modelo y la clasificación común del producto.
- **Reconocedor**: regla que combina estructura, validación y contexto.
- **Diccionario**: colección de términos conocidos asociados a una categoría.
- **Regla de protección**: decisión sobre el tratamiento de una categoría detectada.
