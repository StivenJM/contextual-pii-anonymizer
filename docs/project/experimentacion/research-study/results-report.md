Status: prepared 2026-10-29. **No student study, model training or empirical improvement has been performed as part of preparing this document.** Unmeasured values below must not be interpreted as zero.

## Completed literature findings

A targeted review retained 32 distinct scholarly works, with the exact access depth and limitations in the [evidence matrix](literature-review.md). The supported design conclusions are:

1. Observe submitted behavior as well as reported privacy concerns; include ordinary translation/editing contexts, indirect identifiers and third-party disclosures [R06–R10](references.md#r06).
2. Separate a low-risk fictional-data feasibility pilot from claims about natural real personal-data disclosure; pilot realistic task wording and report its external-validity limits [R13](references.md#r13), [R16](references.md#r16).
3. Evaluate privacy and usefulness jointly; numeric educational content is a necessary negative control [R01](references.md#r01), [R05](references.md#r05), [R12](references.md#r12), [R32](references.md#r32).
4. Separate permission for participation from training/release, document provenance and use held-out participant groups [R18–R23](references.md#r18).

These are literature-supported project design inferences, not local effect sizes. No numerical result from an unrelated paper is substituted for this project's outcomes.
