# Student research kit

**Use this kit first for a synthetic pilot, not for unapproved collection of real student identities.** It contains a 32-paper design review, six original scenario cards, a protocol, instruments, analysis rules, and a report scaffold. The cards are proposed instruments, not validated scales.

## Reading and execution order

1. Read [the plan](../research-capture-plan.md), [literature findings](literature-review.md), and [protocol](protocol.md).
2. Complete the named investigator, ethics, retention, access and provider decisions in the readiness checklist.
3. Prepare [consent and the Google Forms specification](instruments.md). No live Google Form was created or shared.
4. Rehearse the [six scenario cards](scenario-cards.md), using only fictional data and the [local capture guide](../../../guides/research-capture.md).
5. Apply the [annotation and offline analysis plan](analysis-plan.md). Use the [report](results-report.md) only with measured values.
6. Cite [R01–R32](references.md); import [BibTeX](references.bib) if needed.

The [real-data amendment](real-data-amendment.md) explicitly covers the later actual-disclosure question and optional minimal personal-information matching; fictional pilot performance must not be substituted for that outcome.

The [security risk review draft](security-risk-review.md) records remaining risks and the proportionate storage-encryption assessment for owner review. It is not institutional risk acceptance or a claim that every unciphered application record is high risk. See [developer startup](../../../guides/developer-startup.md) for extension installation before service configuration.

## What is ready, and what is not

| Artifact | Readiness |
|---|---|
| Research design, scenario scripts and coding rules | Prepared for investigator review and synthetic rehearsal |
| Reference matrix and citations | 32 distinct works verified at the depth recorded per paper |
| Participant language | English master; a Spanish translation, cognitive pretest and institution-approved final wording remain necessary for a Spanish-speaking study |
| Ethics approval, responsible investigator, retention policy | Not supplied; do not invent them |
| Live external form / recruitment / commercial accounts | Not created or accessed |
| Empirical student findings / model improvement | Not measured; report cells deliberately remain unfilled |
| Software verification | Consult the operation guide for actual observed checks and adapter limits |

This documentation is the English canonical technical master. A researcher must adapt participant-facing material to the participants' language and accessibility needs before fieldwork. Understanding must be checked, not assumed.
