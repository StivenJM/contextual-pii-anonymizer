# Consentimiento y tratamiento de datos

## Propósito

Estas reglas limitan la recolección y conservación de información durante el estudio.

## Reglas

1. **Consentimiento previo**: ninguna sesión experimental comienza sin registrar el consentimiento requerido por el protocolo.
2. **Identidad seudónima**: las personas se identifican mediante códigos; nombres, documentos o correos solo se recopilan cuando exista una justificación expresa.
3. **Minimización**: se conserva únicamente la información necesaria para responder las preguntas de investigación.
4. **Texto original restringido**: el texto inicial completo no se almacena por defecto; cualquier excepción requiere consentimiento, justificación, acceso limitado y un periodo de retención.
5. **Separación de versiones**: cuando se conservan resultados, se diferencia el contenido inicial, transformado, aprobado y enviado.
6. **Retención definida**: cada tipo de dato tiene un periodo de conservación y un procedimiento de eliminación.
7. **Retiro aplicable**: el retiro del consentimiento puede excluir, anonimizar o eliminar datos según el protocolo aceptado.
8. **Exportación mínima**: los resultados exportados excluyen valores identificables que no sean necesarios.
9. **Acceso por responsabilidad**: una persona participante no consulta datos de otras personas; investigación y administración acceden solo a lo necesario para su función.

## Casos especiales

- **Métricas agregadas irreversibles**: pueden conservarse tras un retiro únicamente cuando el protocolo lo permita y ya no puedan vincularse con la persona.
- **Error en el registro**: una operación no se presenta como guardada si la información esencial quedó incompleta.
- **Dato sensible en registros operativos**: debe eliminarse o anonimizarse y tratarse como una incidencia.

## Resultado esperado

El estudio mantiene evidencia útil sin recopilar más información personal de la necesaria y puede responder de forma coherente ante retiros o eliminaciones.
