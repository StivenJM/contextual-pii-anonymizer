# Experimentación

## ¿Para qué sirve?

Este módulo permite evaluar si la asistencia automática reduce la exposición de información sensible frente a la revisión manual. Organiza sesiones, tareas y grupos de comparación sin perder el control sobre consentimiento y minimización de datos.

## ¿Quiénes participan?

- **Participante**: completa las tareas asignadas y decide sobre las sugerencias permitidas.
- **Investigador**: prepara el estudio, supervisa sesiones y analiza resultados.
- **Administrador**: mantiene disponible la configuración necesaria para ejecutar el estudio.

## Capacidades principales

- Crear y finalizar sesiones experimentales.
- Comparar personas con y sin asistencia de protección.
- Diferenciar participantes con y sin formación técnica.
- Asociar interacciones con tareas y versiones del protocolo.
- Medir exposición inicial y residual, aceptación, tiempos y errores.
- Exportar resultados reproducibles con datos minimizados.
- Registrar abandono y retiro del consentimiento.

## Conceptos importantes

- **Sesión experimental**: participación de una persona bajo un protocolo y modalidad definidos.
- **Modalidad**: condición con asistencia de protección o condición de control sin sugerencias.
- **Tarea**: escenario que orienta una interacción evaluable.
- **Exposición residual**: información sensible que permanece en el texto final.
